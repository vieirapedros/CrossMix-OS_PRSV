# BIOS Doctor

Verifica BIOS conhecidas no cartao do TrimUI Smart Pro.

## Uso

Abra **Apps > BIOS Doctor**.

O relatorio e salvo em:

```text
/mnt/SDCARD/Data/biosdoctor/report.txt
```

## Importante

A lista inicial cobre alguns sistemas comuns. Ela pode ser ampliada no arquivo:

```text
Apps/BIOSDoctor/bios.json
```

Nao inclua BIOS proprietarias no repositorio.
