# Smart Pro Game Center

Central simples de favoritos, jogos recentes e registro de tempo de jogo.

Os dados ficam em:

```text
/mnt/SDCARD/Data/gamecenter/
```

## Recursos

- Favoritos por caminho da ROM.
- Historico dos jogos acessados recentemente.
- Registro manual de tempo jogado.
- Base para futura integracao com RomM Library e Port Manager.
