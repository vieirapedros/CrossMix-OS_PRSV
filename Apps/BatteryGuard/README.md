# Battery Guard

Monitora o nivel da bateria do TrimUI Smart Pro e registra o historico.

## Uso

Abra **Apps > Battery Guard**.

O log fica em:

```text
/mnt/SDCARD/Data/batteryguard/battery.log
```

## Configuracao

Edite `Apps/BatteryGuard/config.json` para alterar os limites de aviso e alerta critico.

O app nao desliga o console automaticamente; ele apenas avisa para evitar perda de progresso.
