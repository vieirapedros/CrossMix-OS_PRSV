# Port Manager

Gerencia ports do PortMaster no TrimUI Smart Pro.

## Recursos

- Lista ports instalados em `Roms/PORTS`.
- Instala ports a partir de pasta ou arquivo ZIP.
- Remove ports movendo-os para `.Trash`, sem apagar permanentemente.

Ports sao instalados em:

```text
/mnt/SDCARD/Roms/PORTS/
```
